Add a friend

  1. Open the GHIN app on your phone.
  2. Tap Find Golfer, search for your friend, and note their GHIN number.
  3. Tap the button below to open friends.json on GitHub.
  4. Add an entry like { "ghin": "1234567", "name": "Jane Smith", "club": "Pebble Beach" } inside the [ ] brackets (commas between entries).
  5. Commit. The next daily run picks them up — or trigger Actions → Run workflow for an instant update.
