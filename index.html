Connect

This app needs two credentials, both stored only on this device:

  • A GitHub token — lets the app update friends.json and trigger the daily snapshot.
  • Your GHIN email + password — lets the app search GHIN when you add a new friend, so you can pick the right person from the list.

GitHub fine-grained Personal Access Token:

  1. Tap the link below to open GitHub's token page.
  2. Token name: ghin-friends app. Expiration: whatever you want.
  3. "Repository access" → Only select repositories → ghin-friends.
  4. "Repository permissions": Contents = Read and write, Actions = Read and write.
  5. Generate, copy the token (starts with github_pat_), and paste below.

Open GitHub token page →

GHIN credentials:

Same email + password you use to log into the GHIN mobile app.
