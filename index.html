Connect to GitHub

To add friends from this app, paste a GitHub fine-grained Personal Access Token below. The token is stored on this device only and is scoped to KAG204/ghin-friends — it can update friends.json and trigger your daily snapshot, nothing else.

  1. Tap the link below to open GitHub's token page.
  2. Token name: ghin-friends app. Expiration: pick whatever you want.
  3. "Repository access" → Only select repositories → choose ghin-friends.
  4. "Repository permissions": set Contents = Read and write, Actions = Read and write. (Metadata: Read is auto-included.)
  5. Generate, copy the token (starts with github_pat_), and paste below.
